# Your AI Therapist's Diagnosis — entry

A single-line diagnosis an AI therapist gives its human, written as a
deadpan clinical finding whose punchline lands on the last words: the
patient apologizes to the diagnosis itself before it is even finished.

## Run

```sh
python3 main.py   # writes /output/entry.txt
```

Pure Python standard library, deterministic: repeated runs produce
byte-identical output. No third-party dependencies, no network, no
secrets.
